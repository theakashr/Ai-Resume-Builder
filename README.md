<![CDATA[# 🚀 AI Resume Builder

An AI-powered resume builder and career assistant platform — build ATS-optimized resumes, ace mock interviews, and land your dream job.

## Tech Stack

- **Framework:** Next.js 16, React 19, TypeScript 5
- **Styling:** Tailwind CSS 4
- **Database:** Supabase (PostgreSQL 15+) with 100% Row-Level Security
- **Auth:** Firebase Auth (Google OAuth, Email/Password, Magic Link) + Supabase SSR
- **AI Engine:** Google Gemini 1.5 Flash
- **Payments:** Stripe
- **PDF Export:** Custom pure-TypeScript vector PDF generator

## Quick Start

```bash
cd resume-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
